# 🛍️ e-Shop  

A modern and responsive e-commerce website built using **HTML, CSS, and JavaScript**. The project provides a premium shopping experience with a futuristic glassmorphism UI, product filtering, search functionality, shopping cart, promo codes, and responsive design.

## 🚀 Live Demo

> Live demo
> https://indexhtml-rose-chi.vercel.app/

---

## ✨ Features

- 🎨 Modern Glassmorphism UI
- 🔍 Real-time Product Search
- 📂 Category Filtering
- 🛒 Shopping Cart
- ➕ Increase/Decrease Product Quantity
- ❤️ Wishlist Button
- 🎟️ Promo Code Support
- 📦 Product Details Modal
- 📱 Fully Responsive Design
- 💾 Local Storage Support
- ⭐ Product Ratings
- 🔔 Toast Notifications
- 🌈 Animated Hero Section
- ⚡ Smooth Animations

---

- HTML
- CSS
- JavaScript
- Local Storage API

## ⚙️ How to Run

1. Clone the repository

```bash
git clone https://github.com/ashish-dev-hub/BDCOE-Project.git
```

2. Open the project folder

```bash
cd e-Shop
```

3. Open `index.html` in your browser.

No installation required.

---

## 🛍️ Main Functionalities

### Product Listing
- Displays all available products.
- Dynamic product rendering.

### Search
- Search products instantly.

### Category Filter
- Electronics
- Jewelry
- Men's Clothing
- Women's Clothing

### Shopping Cart
- Add products
- Remove products
- Increase quantity
- Decrease quantity
- Clear cart


### Promo Codes

| Code | Discount |
|------|----------|
| BDCOE25 | 25% |
| SNEAKR20 | 20% |

## 💾 Local Storage

The shopping cart is saved in the browser using Local Storage, so cart items remain available even after refreshing the page.
